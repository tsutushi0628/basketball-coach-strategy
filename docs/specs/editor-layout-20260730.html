編集画面は1列を「この日の基本／内容の用意／時間割／確定」の4つの節に分けた。3択は「この日の対象」というラベルを付けて横一列にし、選ぶと他のタブと同じオレンジで塗る。節と節の間はフィールド間より広く空けて、切れ目が余白で読めるようにした。
