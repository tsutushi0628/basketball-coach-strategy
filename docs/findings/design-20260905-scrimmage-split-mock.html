チーム分け（/scrimmage）の3フレーム

独立 URL /scrimmage。ホーム画面に追加して直接開く。練習計画の画面からは入らない。入れ替えは無し、気に入らなければもう一回。

出欠を確認してチーム数を決めて分ける。結果はチームの文字と名前だけを出す。順位付けと読める語や数は、どの面にも出さない。

各フレームは幅390pxで描いてある。部品の見た目は docs/design-system/component-spec.md の5役割（状態ピル／主の操作／副の操作／下線の文字）に揃えた。

面1: 出欠とチーム数
ホーム画面のアイコンから開く最初の面。上で男子か女子を選び、来ていない子のチェックを外し、チーム数を選んで「分ける」を押す。
在籍中は全員チェック済みで開く。今日は2人が欠席で外れている。行に出すのは名前だけ。人数の行は出席人数と割り方を示す。ヘッダ右端の下線の文字「名簿」は管理者にだけ出て、面3へ跳ぶ。
